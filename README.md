# Raj in JP

Website: https://raj-in-jp.github.io

- `index.html`, `style.css`: the site (minimal washi-paper theme, light/dark)
- `free/`: free hiragana/katakana charts and writing practice PDFs
- `app.js`: kanji practice (flashcards + quiz by level, "Learn about this kanji" pop-up) and the kana quiz (every kana once per round)
- `assets/kanji-data.js`: all 612 JLPT N5–N3 kanji (levels: Jonathan Waller lists; KANJIDIC2 CC BY-SA 4.0)
- `assets/strokes/`: stroke order per kanji (KanjiVG CC BY-SA 3.0)
- `analytics.js`: paste your Google Analytics ID to turn on visit stats
